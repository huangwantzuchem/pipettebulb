# 吸量管＋安全吸球＋燒杯｜操作模擬

這是一個以 HTML Canvas + JavaScript 製作的化學實驗器材互動模擬。

## 使用方式

直接開啟 GitHub Pages 網站即可操作，不需要安裝任何程式。

### GitHub Pages

將本專案的 `index.html` 放在 Repository 根目錄，並在：

**Settings → Pages → Deploy from a branch → `main` / `(root)`**

啟用 GitHub Pages。

啟用後，GitHub 會提供一個類似以下格式的網址：

`https://你的GitHub帳號.github.io/你的Repository名稱/`

## 目前功能

- 吸量管＋安全吸球＋燒杯互動模擬
- A／S／E 按鈕操作
- 吸液與排液
- 吸量管體積顯示
- 超過 25.5 mL 時，安全吸球 E 按鈕顯示紅色閃爍警示
- 體積降至 0.0 mL 後不會繼續變成負值
- 響應式版面，可在電腦與行動裝置使用
